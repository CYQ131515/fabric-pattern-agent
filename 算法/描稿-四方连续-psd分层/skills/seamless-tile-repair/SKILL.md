# 可平铺花版修复 · 技术手册

先记住一条硬约束（L12）：**缝带是全高竖条 + 全宽横条**。替换整条内容后：
- 竖条的**上下两端**在平铺时必须自我衔接；
- 竖条**左右边界**与原图接壤处不得切断图案。
只满足其一的方案都会在用户放大/平铺时露馅。

## 验收指标（先定标准，再选方法）

1. **wrap ratio**：平铺接缝处差异 / 相邻像素差，必须 ≤1.2（横竖各一）；
2. **带边界检查**：四条缝带边界 1:1 无直线切断、无亮度台阶、无双影；
3. **内部十字**：1:1 内容自然延续；
4. **合成保真**：PSD 合成 vs 无缝图 `max_abs_diff == 0`。

## 方法决策树

```
输入 → 是否有明确重复单元？
├─ 有（花型可整块取用）→ quilt 拼贴 / 取单元做 tile
└─ 无
   ├─ 图案稀疏 + 纯色/渐变底 → AI 清洗 + 原生重生成（多采样，wrap 硬筛）
   ├─ 纹理密集（水彩/笔刷/噪点）→ 见下
   └─ 线稿/涂鸦 → 原生重生成 或 图割缝合（不要用 AI 缝带，会切断描边 L05）
```

**纹理密集图的坑（本次实测）**：

| 方法 | 结果 | 原因 |
| --- | --- | --- |
| AI 缝带修复（band 120-160） | 内部十字自然，但**带边界切断**；wrap 59 | 全高竖条上下不衔接 + 边界内容差 |
| 确定性补缝（quilt+multiband） | wrap 合格，但**细缝线**可见 | 多频段融合留下线状痕迹 |
| 原生重生成（sunburst/ext） | 布局干净，但**模型不保证可平铺**（wrap 34-61） | 生成模型不理解严格 tile 约束 |
| 掩膜 inpaint 缝线 | 失败：模型不遵守 mask，整图重绘 | 需强约束/局部 inpainting 引擎 |
| offset+交叉淡化 | wrap 1.6-2.5，仍非无缝 | 竖条内替换后上下仍不衔接 |

## 真正可能闭环的做法（按优先级）

1. **wrap-aware 条带修复**：在竖条内部再做一次纵向 offset+淡化，使条带自身上下可平铺；
   横向边界用窄羽化；验收 wrap≤1.2 后再看 1:1。
2. **图割 / 最小误差路径缝合**：在重叠区用 DP 找低对比路径切缝，再窄带融合（经典 texture quilting）；
   适合纹理/笔刷类，不改变内容。
3. **多采样生成 + 硬指标筛选**：重生成 3-5 张，只接受 wrap≤1.2 且无直线的；成本高但确定性最好。
4. **最终兜底**：都不过就不交付，记录案例（宁可不出件，不交坏件）。

## 区域框选修复（局部瑕疵/单条缝线）

```bash
# 自动修一条线（分段，Poisson 融合）
python steps/06-repair-region.py --image tile.png --out fixed.png --line v:512 --pad 80 --mask-width 26 --seg 320 --scale 3
# 用户指定框选
python steps/06-repair-region.py --image tile.png --out fixed.png --box 400,300,200,200 --mask-box 30,30,140,140 --scale 3
```

- 只改框内、Poisson 贴回 → wrap/其它内容不受影响；
- 坑（L17）：窄条里模型可能生成杂色 → 必须多采样 + 自动打分（颜色合理性/边界梯度）；
- 修完必须从最终 PSD 合成图 1:1 复检（L15）。

## 迭代纪律

- 每次失败必须记录：方法 / 参数 / wrap 指标 / 1:1 现象 / 根因（case + lessons）；
- 同一特征簇连续失败 ≥2 次 → 切换方法族（而不是继续调参）；
- 任何新方法先过回归集（坏图必须被打回、好图不能误报）再上线。
