# 失败模式速查（来自面料描稿项目实测）

| 编号 | 现象 | 根因 | 规避 |
| --- | --- | --- | --- |
| L01 | 中间接缝漏检 | 只检查外缘；平移把原图边缘移到内部 | 整图扫离群直线 |
| L02 | 矩形色块 | 确定性补缝用于渐变/平涂 | 渐变图禁用 det |
| L03 | 贴图块+硬边 | AI 补缝 band>200 | band 120–160 |
| L04 | 条纹/光晕 | AI 补缝后做 Laplacian/Poisson 融合（几何错位） | 不做后融合 |
| L05 | 描边被切断 | 线稿用 AI 带补缝 | 线稿走重生成/图割 |
| L06 | 矩形 overlay | 生成模型画出画布边界痕迹 | 需要矩形检测器/裁边 |
| L11 | 外缘永不连续 | seam-ai 合成回了未平移的 base | 合成基准必须是 off 平移图 |
| L12 | 平铺后仍有断口 | 全高竖条替换后上下不衔接 | wrap-aware 修复/图割/多采样筛 |

## 指标
- wrap ratio = 平铺接缝差异 / 相邻像素差（目标 ≤1.2）
- 带边界 1:1：无直线、无台阶、无双影
- PSD 合成 max_abs_diff = 0
